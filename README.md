## 🚀 快速部署

### 环境要求
- WordPress 5.5+
- PHP 7.4+（推荐8.3）
- MySQL 5.7+ / MariaDB 10.3+
- Nginx/Apache 服务器

### 安装步骤
1. 下载本主题全部文件
2. 解压后将 `xingtang` 文件夹上传到 `/wp-content/themes/` 目录
3. 登录 WordPress 后台 → 外观 → 主题 → 启用「星棠化妆培训学校」主题
4. 进入「设置 → 固定链接」，选择「文章名」，保存（刷新伪静态）
5. 进入「主题设置」后台，配置：
   - 首页轮播图4张
   - 学校基本信息（名称、电话、地址）
   - 校区信息
   - SEO 关键词
6. 创建页面：
   - 首页 → 页面模板选「首页」
   - 新闻列表 → 页面模板选「新闻列表」
   - 其他页面根据需要选择对应模板
7. 访问首页即可看到完整效果！
